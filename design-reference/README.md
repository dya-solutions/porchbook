# Design reference

These files are the agreed screen designs for JT's Porchbook (see BUILD-BRIEF.md). Each `.dc.html` file is one phone screen, 390 x 844 px. Read them as the picture of what to build: layout, wording, spacing, colours (Porch Evening theme) and icons. They are design files, not app code: don't copy them into the app or try to run them (the `support.js` line only works in the design tool).

| File | Screen |
| --- | --- |
| Main.dc.html | Welcome: join with an invite code, or start a porch |
| Porch.dc.html | My porch: feed, rooms, "on the porch now" strip, office announcement |
| Tour.dc.html | Tour doors |
| Chat.dc.html | Chat list, with office conversations and online dots |
| Offices.dc.html | List of the church's offices |
| Office.dc.html | One office and its actions, with your requests |
| OfficeThread.dc.html | A conversation with an office |
| Read.dc.html | Bible, the church's books, my notebook |
| Public.dc.html | Public porch: porches post, members react |
| PorchPage.dc.html | A porch's public page with its branches |
| StartPorch.dc.html | Start a porch, including "this is a branch" |
| Presence.dc.html | Who is on the porch, with the visibility switch |
| Conversation.dc.html | Messaging a member, with call buttons |
| Call.dc.html | A one-to-one voice call |

The names, posts and messages are made-up samples.
